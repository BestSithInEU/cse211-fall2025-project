\section{Project Overview}

This project is designed to assess your understanding of data structures through the implementation of a complete software system. You will design, build, and present a \cpp{} application that demonstrates mastery of fundamental data structures by implementing them from scratch and applying them to solve a real-world problem.

% ── Objectives ──
\subsection{Objectives}

\begin{enumerate}
  \item Demonstrate proficiency in implementing custom data structures from scratch.
  \item Apply algorithmic thinking to solve problems using appropriate data structures.
  \item Develop skills in software architecture and modular design.
  \item Practice professional software development workflows including documentation, testing, and version control.
  \item Create user interfaces that effectively present and interact with your solution.
\end{enumerate}

% ── Project Scope ──
\subsection{Project Scope}

Your project must encompass the following:

\begin{itemize}
  \item Analyzing a problem domain and selecting appropriate data structures.
  \item Designing and implementing at least two (2) custom data structures.
  \item Building a complete application with clear modularization.
  \item Creating a user interface (console, GUI, or web).
  \item Writing comprehensive tests covering unit, integration, and edge cases.
  \item Presenting your design through UML diagrams.
\end{itemize}

% ── Important Notes ──
\subsection{Important Notes}

\begin{itemize}
  \item You \textbf{must} implement data structures from scratch --- STL containers are not allowed as primary storage.
  \item Code quality is as important as correctness.
  \item All work must be original --- plagiarism results in a zero grade.
  \item Follow all formatting and documentation standards described in this document.
\end{itemize}
